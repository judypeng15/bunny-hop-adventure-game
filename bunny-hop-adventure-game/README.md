# Bunny Hop Adventure Game

A colorful browser game with Bunny Hop Adventure, Quiz Cash Dash, and Carrot Catch.

## Play the game

Open `index.html` in a browser, or publish this folder as a static website. Keep `bunny-hop-logo.svg` in the same folder as `index.html` so the browser tab icon appears.

## Search title

**Bunny Hop Adventure Game**

The page title and description are set for this phrase. Search engines may take time to discover a newly published site.
